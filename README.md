# MoviesAdmin

# What is Movies Admin?
Its the admin panel of the Movie rating website that will allow moderators to edit and change anything that needs to happen in the sight itself. By the end it'll be a fully functional administration panel for quicker and easier access to whatever an admin might need.

# Why is it important?
It will speed up the process at which changes can be performed at, which will intern make the sight smoother and operate and a faster pace.
